# لَمّة البيت — VORTEXweplab

## النسخة
تثبيت الأغلفة والمشغّل — 27 أكتوبر 2026.

## الملفات الأساسية
- `public/index.html`: المكتبة الرئيسية والبانر السينمائي.
- `public/details.html`: تفاصيل الفيلم أو المسلسل.
- `public/watch.html`: مشغّل الفيديو وعناصر التحكم.
- `public/admin.html`: لوحة إدارة المحتوى.
- `public/firebase-config.js`: إعدادات عميل Firebase الحالية.
- `firebase.json`, `firestore.rules`, `storage.rules`: إعدادات Firebase الحالية.

## التصحيحات في هذه الجولة
- توحيد دعم حقول الأغلفة الحالية والقديمة عبر الرئيسية والتفاصيل والمشغّل والأدمن.
- إضافة صورة احتياطية مصغّرة من YouTube عند غياب الغلاف الصريح، مع قصر روابط الصور المقبولة على HTTPS.
- توحيد التعرف على روابط YouTube القديمة بين الرئيسية والتفاصيل والمشغّل، وإصلاح رابط الرجوع إلى YouTube في حالة فشل التضمين.
- إصلاح تعامل عارض الذكريات مع سجلات قديمة تحتوي غلافًا في `coverUrl` أو `thumbnailURL` أو حقول مماثلة.
- جعل معاينة الأدمن ومؤشر المحتوى بلا غلاف يستخدمان نفس آلية اكتشاف الغلاف.
- تحسين استيراد النسخة الاحتياطية حتى لا يفقد بعض حقول الأغلفة القديمة عند تحويلها إلى `posterUrl`.
- إضافة بوابة تأكيد أمني قبل نشر Hosting.

## الفحص
اقرأ `TEST_REPORT_AR.md` لنتائج الاختبارات التي نجحت والاختبارات التي تعذّر تأكيدها، و`SECURITY-REVIEW_AR.md` لمشكلة الأمان المهمة. نجحت اختبارات الصياغة والروابط المحلية و22 اختبار وحدة للأغلفة ومسارات التشغيل. لم ينجح/يكتمل اختبار Chromium التفاعلي لأن بيئة التنفيذ تمنع التنقل، ولم يتم الاتصال بـ Firebase الحي أو النشر.

## تحذير قبل النشر
**لا تعتبر هذه النسخة جاهزة لإطلاق عام آمن بعد.** قواعد Firestore الحالية تمنح الزائر صلاحيات الكتابة والحذف في المكتبة، وقواعد Storage تسمح بالحذف العام، ولوحة الأدمن بلا تسجيل دخول. سكربت النشر يعرض الخطر ويتطلب كتابة `DEPLOY-ANYWAY` للمتابعة. الإصلاح الصحيح هو إضافة Firebase Authentication للإدارة واختبار قواعد آمنة قبل النشر العام.

## النشر
من Windows، فك ضغط الحزمة بالكامل، وثبّت Firebase CLI وسجّل الدخول إلى المشروع الصحيح. شغّل `DEPLOY-WINDOWS.cmd` من مجلد المشروع. السكربت ينشر Hosting فقط؛ لا ينشر قواعد Firestore أو Storage، ولن يتابع إلا بعد إقرار صريح بالمخاطر الأمنية الحالية.

## الحفاظ على البيانات
لم يتم تعديل بنية مستندات Firestore أو حذف أي سجلات. تصحيحات الأغلفة تقرأ حقولًا قديمة، وعند استيراد النسخة الاحتياطية تضع الغلاف المكتشف في `posterUrl` القياسي. لم يتم تشغيل الاستيراد أو النشر على البيانات الحية.
