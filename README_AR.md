# لَمّة البيت — جاهز لـ GitHub Pages

## خطوات النشر

1. أنشئ مستودع GitHub جديدًا باسم `lammet-elbeit`.
2. فك ضغط الحزمة وارفع كل الملفات الموجودة داخلها إلى جذر المستودع (ومنها `index.html` و`admin.html`). لا ترفع ملف ZIP وحده.
3. ادخل إلى **Settings → Pages**.
4. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)` واضغط **Save**.
5. بعد اكتمال النشر، رابط البرنامج سيكون غالبًا `https://USERNAME.github.io/lammet-elbeit/`، ورابط الأدمن `https://USERNAME.github.io/lammet-elbeit/admin.html`؛ استبدل `USERNAME` باسم حسابك.

الروابط دي قوالب وليست منشورة فعلًا قبل إنشاء المستودع وتفعيل Pages.

## مهم جدًا — أمان الأدمن

لوحة الأدمن بلا تسجيل دخول، ومراجعة قواعد Firestore في المشروع وجدت أن أي شخص يستطيع قراءة وإضافة وتعديل وحذف عناصر `episodes`. نشر لوحة الأدمن للعامة يعرّض مكتبتك للتغيير أو الحذف. الحل الصحيح هو تفعيل دخول إداري وتقييد قواعد Firebase قبل الإطلاق العام. هذه الحزمة لا تغيّر قواعد Firebase ولا الموقع الحالي.
