# لَمّة البيت — VORTEXweplab

نسخة جاهزة للنشر كموقع ثابت على GitHub Pages. ملفات الموقع موجودة في جذر هذا المستودع، و`index.html` هو المدخل الرئيسي.

## نشر البرنامج ولوحة الأدمن

1. افتح GitHub وأنشئ مستودعًا جديدًا باسم `lammet-elbeit` (Public إذا كنت تستخدم GitHub Free).
2. فك ضغط هذه الحزمة، وارفع **محتويات المجلد نفسها** إلى جذر المستودع؛ لا ترفع ملف ZIP وحده ولا ترفع المجلد الأب كطبقة إضافية.
3. من المستودع افتح **Settings → Pages**.
4. في **Build and deployment** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/(root)`، واضغط **Save**.
5. بعد نجاح النشر، ستجد رابط الموقع في صفحة Settings → Pages.

إذا كان اسم حسابك `USERNAME` واسم المستودع `lammet-elbeit`، يكون شكل الرابط عادةً:

- البرنامج: `https://USERNAME.github.io/lammet-elbeit/`
- الأدمن: `https://USERNAME.github.io/lammet-elbeit/admin.html`
- تفاصيل العمل: `https://USERNAME.github.io/lammet-elbeit/details.html`
- المشغّل: `https://USERNAME.github.io/lammet-elbeit/watch.html`

استبدل `USERNAME` باسم حساب GitHub الحقيقي. الروابط أعلاه قوالب وليست روابط منشورة بعد.

## Firebase

الصفحات تستخدم إعداد Firebase الموجود في `firebase-config.js` للوصول إلى مكتبة المشروع الحالية. GitHub Pages يستضيف واجهة الموقع فقط؛ لا يغيّر إعدادات Firebase ولا ينشر قواعد Firestore/Storage.

## تنبيه أمان مهم

لوحة الأدمن الحالية لا تتطلب تسجيل دخول، وملف مراجعة المشروع وجد أن قواعد Firestore الحالية تسمح لأي شخص بالقراءة والإضافة والتعديل والحذف على مجموعة `episodes`. لذلك نشر لوحة الأدمن للاستخدام العام قد يسمح لأي شخص بتغيير المكتبة أو حذفها. لا تعتبر إخفاء رابط الأدمن حماية. قبل مشاركة الموقع على نطاق عام، ينبغي تأمين الكتابة عبر Firebase Authentication وقواعد صلاحيات مقيّدة ثم اختبارها. لم تتضمن هذه الحزمة قواعد Firebase ولم تغيّر المشروع الحي.

## ملاحظات

- استخدم روابط ملفات الصور المباشرة للأغلفة، وليس صفحة مشاركة صورة.
- رابط الفيديو يجب أن يكون رابط YouTube مدعومًا أو رابط فيديو مباشرًا صالحًا.
- هذه الحزمة لا تُنشئ المستودع ولا تنشره تلقائيًا؛ النشر يتم من حساب GitHub الذي تملكه.
